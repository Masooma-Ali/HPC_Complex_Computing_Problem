BUILD PROCESS:
==============

The build process now:
  1. Compiles CPU support files (error.c, pnmio.c, pyramid.c, etc.)
  2. Compiles GPU files (convolve.cu, trackfeatures.cu) with nvcc
  3. Creates libklt_gpu.a archive
  4. Links example3.c with GPU library
  5. Produces example3_gpu executable

Note: trackFeatures.c is NOT compiled - replaced by trackfeatures.cu

  - Verify compute capability: nvidia-smi --query-gpu=compute_cap --format=csv
  - Ensure CUDA drivers installed

  - Verify GPU is being used: nvidia-smi (while running)
  - Check GPU utilization should be 30-90%
  - Try larger images for better GPU utilization
